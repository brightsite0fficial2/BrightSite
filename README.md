# Portfolio Site

A joint portfolio built with React + Vite, showcasing both team members' skills, experience, and
projects, plus your service offering (fast, secure websites).

## Before you launch
1. Open `src/data.js` and replace `BRAND.name` / `BRAND.short` (currently "[Your Studio Name]" /
   "[YSN]") with your real studio/brand name.
2. Review the copy in `src/data.js` — everything is pulled from your CVs, so double-check details
   and update anything that's changed since.

## Run locally
```
npm install
npm run dev
```
Then open the printed local URL (usually http://localhost:5173).

## Deploy to Vercel
1. Push this folder to a GitHub repo.
2. Go to vercel.com → New Project → import the repo.
3. Vercel auto-detects Vite — just click Deploy. No config needed.

(Or install the Vercel CLI and run `vercel` from this folder.)
